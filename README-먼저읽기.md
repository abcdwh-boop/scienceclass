# 기몬의 과학서재 — 최종 배포용 (위치 편집기 제거)

## 반영된 내용
- 직접 드래그하여 정한 책 좌표를 `books-layout-overrides.js`에 반영했습니다.
- 관리용 위치 편집 버튼 / 패널 / 브라우저 임시 저장을 제거했습니다.
- 기존 서재 이미지, 책등 움직임, 클래식 책 펼치기, 링크와 목록 보기는 유지했습니다.
- `books-layout.js`는 원본 기본 좌표로 남겨 둡니다. 미세조정 좌표가 있으면 보정값이 우선 적용됩니다.

## 실행하기
압축을 풀고 `index.html`을 실행하면 됩니다. 책등 클릭 시 페이지가 펼쳐지고 링크가 등록된 책은 새 탭에서 열 수 있습니다.

## 배포하기
**중요:** GitHub 저장소 최상위(현재 홈페이지 `index.html`이 있는 위치)에 이 폴더의 파일과 `assets` 폴더를 업로드/덮어쓰기 하세요.

- `index.html`, `style.css`, `app.js`, `library-data.js`, `books-layout.js`, `books-layout-overrides.js`를 함께 올려야 합니다.
- `assets/library-background.webp` 파일도 꼭 있어야 합니다.
- 기존 다른 수업 페이지의 폴더는 **삭제하지 마세요.**
- 적용 전 기존 메인페이지 관련 파일은 백업해 두세요.

## 나중에 책 내용을 수정하는 곳
`library-data.js` 하나만 수정하면 됩니다. 한국어 주석을 달아 두었습니다.

- `siteTitle` : 홈페이지 제목
- `siteSubtitle` : 소개 문구
- `sections` : 수업·평가·AI&에듀테크 구역 이름
- `books` : 책등 제목 `spineTitle`, 펼친 책 제목 `title`, `url`, `description`

책 위치 번호(예: `lesson-1-03`)는 **계속 같은 번호를 사용**합니다. 책등이 어디에 있든 책 정보와 연결되는 번호는 변하지 않습니다.

## 주의
- 조정 좌표는 `books-layout-overrides.js`에 저장돼 있습니다. 이 파일을 삭제하면 책들이 원래 위치로 돌아갑니다.
- 이 배포용 파일에서는 더 이상 웹페이지에서 책 위치를 드래그하여 편집할 수 없습니다.
- 나중에 다시 위치를 수정하려면 보관해 둔 v2 편집기에서 작업한 뒤 새로운 `books-layout-overrides.js`를 배포용에 덮어쓰면 됩니다.
- 기존 브라우저 localStorage 좌표는 이 배포 버전에 영향을 주지 않습니다.
